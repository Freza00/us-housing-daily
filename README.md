# US Housing Daily

美国住宅地产工作日新闻与研究摘要，覆盖全国住宅、Sun Belt、BTR／SFR、CRE 和机构资本。静态页面由 Vercel 托管，生成任务由 GitHub Actions 执行。当前开发及发布状态见 [ROADMAP.md](ROADMAP.md)。

## 运行时间

以下均为北京时间，实际生成完成时间取决于抓取和模型响应。

| 报告 | 触发时间 | 内容窗口 |
| --- | --- | --- |
| 日报 | 周一至周五 05:00 主触发，目标 09:00 前可读 | 各来源从上次成功采集的截止点续接至本日 05:00 |
| 周报 | 周一 14:00 首跑，目标 15:00 前可读 | 美东上周一 00:00 至本周一 00:00，覆盖完整自然周 |
| 月报 | 次月首个工作日 15:00 首跑，目标 16:00 前可读 | 上一个已结束的美东自然月 |

北京时间周六、周日，生产脚本和触发接口均在抓取及模型调用前退出，包括强制生产运行。截稿后的消息进入下一期。每源水位仅在有效覆盖且原始材料落盘后推进；失败源保留旧水位，已有水位不按固定小时数或 7 天上限截断。只有没有历史记录的首次运行，才以此前一期截止点或上一工作日 05:00 初始化，并记录 lower_basis。历史回放有独立输出和状态目录。

工作日按北京时间周一至周五计算，不另排除法定节假日；月报首个工作日在月初 1—3 日。周期起点包含、终点不包含，新闻按原始发布日期归期，报告中的数据统计期单独注明；采集、生成或补发延迟不移动截稿点。美东自然周使用当地日历处理夏令时，可能为 167／168／169 小时。

周报复用期内原始材料与已写日报，并对同一周期重新检查重要研究；周一日报模型失败时，直接读取已保存的待处理材料，不等待日报成稿。周／月报同日分别于 14:00／15:00 首跑，互不依赖对方成功，沿用共享发布队列。09:00／15:00／16:00 分别是日报／周报／月报的可读目标；GitHub 排队、源站和模型故障仍可能使发布延后，主触发与错峰补偿检查共同增加余量。

日报 Actions 补偿检查配置为工作日 05:17、06:17、07:17、08:17、09:17；已有合格同期归档时直接跳过生成。距可读目标超过 3 分钟时，为交付预留 3 分钟并收缩模型时间预算；进入预留窗或迟到恢复时，使用同版 660,000 ms 总预算的剩余额度。预留窗前不另设最小请求窗口阈值，临近边界时剩余预算可能极小；这不保证每个时间点均能完成请求。累计调用耗时及退避达到总预算后仍禁止新增模型请求，不因重试重置账本。

新闻卡片统一显示原始发布日期 YYYY-MM-DD；明确提供时刻的来源可悬停查看美东时间，仅日精度或旧稿未确认精度时不展示具体小时。周／月页面单独显示归档真实内容窗口，生成时间另列；旧归档不随新规则改写。

日报日期条与日历以北京期号日显示。切刊、选期和刷新共用请求身份，过期请求不覆盖新视图；目录读取失败时保留已知日期，并允许正文独立加载。加载失败后显示当前错误，切换语言不会恢复上一期卡片。跨期筛选有匹配时保留，无匹配时返回全部。

英文卡片显示已核验的原文证据节选，标为 Source excerpt，不把源站导航前缀当作摘要；旧刊缺少英文节选时提示查看原文。标签显示覆盖配置中的四维词表，全国地域标签明确隐藏；Sun Belt 筛选和计数使用同一完整地域集合。

## 生成流程

1. 脚本采集 RSS、官方研究目录、报告正文与公开 PDF；使用并发上限、请求超时、条件请求和缓存。短摘要或缺日期的 RSS 先有界补文，再判断日期和证据资格。正文优先从匹配文章标题的位置提取，剔除导航和侧栏；普通候选提供前 1,000 字符、研究候选提供前 1,200 字符证据。
2. 脚本规范 URL、去重、过滤已刊条目，并按出版机构分配候选机会，最多给模型 72 条。日报在原 72 次补文尝试内先为 BTR／SFR、机构资本、非多户 CRE 各留最多 3 条机会，CRE 先覆盖不同资产；这是取文线索，不决定最终栏目。自存储、养老及生命科学标题进入非多户资产线索识别。先前正文不足但日期有效的线索允许在冻结前补文，补文后仍不足就排除。候选快照记录各类可用线索、尝试、正文可读数、资格通过数和逐原因排除数。日报在分配候选预算前区分原料保留与出版资格：首次发现的超期旧稿留存审计，但不自动入选；本期材料和有原始采集区间记录的未处理积压可入池，不任意截断停源恢复或模型失败的材料。旧版积压只从原始快照的日期区间或逐源覆盖证据恢复资格，不拿扩大的 pending 包络证明时效。固定报告 URL 同时记录日期和正文版本；没有新日期的内容变化列为待核实，不自动当作今日报告。明确标记正文不足的材料不送编辑模型，补文后再次检查。
候选初排先保障必需研究和各出版机构的机会，再按普通媒体 4 条／研究 5 条分配初始配额；总容量未满时，按原全局排序从剩余去重池增补。候选补文与资格复验均在 prepared 冻结前完成，最多检查 72 个不同候选，失败也消耗检查额度，允许实际送审不足 72；不在模型选稿后增加补审循环。阶段快照记录初始数量、尝试、合格和排除数量。候选机构初始配额与最终刊出的机构上限分别执行。

3. `gpt-6.1-sol` 以显式 `medium` 判断重要性、语义重复、实际资产／主题地域与主事件。标签含义和维度限制直接来自 `config/tags.json`；模型返回单值 `asset`／`geo`／`actor`（参与者可为空）、至多两个 `topics`、非全国 `geo_evidence`，不输出自由 tags 或决定 section。周／月报和旧协议另返回 `capital_focus`；新日报使用下述编号协议。模型边界逐字段按配置严格检查并展平为既有 tags；未知地域或多参与者不会被静默映射或删除。脚本验证标签、地域片段及重复关系后统一归栏，成品发布前再用同一函数复验。模型只接触本批短编号；程序验证后映射回稳定 ID。拒稿不必分类打标签：程序统一其 importance／section／tags 为 1／null／[]，先检查未修改的全部去重关系，再清空拒稿指向拒稿 root 的无出版用途关联。保留稿字段及所有编号、未知目标、自指、链和环仍严格检查。没有固定星级分布，不强凑 20 条。
归栏顺序为 BTR／SFR → 主事件为基金／平台资本动作或机构资本治理风险 → 非住宅及混合资产 CRE → Sunbelt 住宅／多户 → 其他多户 CRE → 全国住宅／住房金融。普通财报、物业交易和背景资本动作不自动进入机构资本栏。行业普适监管、监管机构自身预算或行动范围收缩按行业政策处理；机构资本监管风险须直接针对可识别资本主体的资金管理、受托责任、资本运作或治理。地域不采用总部或来源所在地；有明确主题片段时将 texas／sun-belt 细化为 Houston、DFW 或 Austin。连续片段仅将大小写、直弯引号和连续空白视为等价，标题与正文分别匹配并保存实际原文写法；不删除标点、跳词或拼接两字段。新日报按选中原文内地域短锚的位置和主题角色检查总部背景；旧协议保留原句检查。地域细化只用已经匹配的原文，重复验证保持一致。片段存在及标签一致性校验不能代替原文语义核查。

新日报标记 `editorial_protocol=evidence-refs-v1`。prepared 冻结实际编辑窗口及逐段编号；模型输出 `primary_event`、事件证据号、`market_scope`、范围证据号和 `market_role`，程序绑定原文并派生 `capital_focus`。物业及物业组合交易／融资与基金／平台资本动作分开；机构整体配置研究保留机构资本属性。总部搬迁本身可作为办公事件，总部背景不能充当标的地域。非法编号、短锚未命中、角色与主事件冲突，在 editor 冻结前集中进入既有局部修复，保持其他决定和去重图；明确非美国与无法验证另记原因。三次请求耗尽仍未验证时不冻结整批 editor，不启用逐条编辑降级。编号与角色不能代替全部语义核查。

日报冻结输入还保存此前 4 个工作日的已刊标题与短摘要（最多 80 条），在同一次 editor 调用中核对跨期事件。只有独立新增事实或实质行动才保留跟进，换来源或重述声明不另占条数；冷恢复复用冻结台账。通用月度 Jobs／Employment Report 额外保存统计月和原文窗口：重复统计月须提供当前输入中的新增数据原句，且新增数值实际进入中文成品，否则在选稿及发布前排除；独立行业研究和不同统计月保持各自身份。发布器以当前远端的近期归档复查，人工组稿也须通过。该确定性检查只覆盖这类月度快报，其他事件仍由 editor 判断。

补文优先桶只认标题中明确且无歧义的主体资产，不使用正文关键词召回标签；多资产和用途转换等标题留给编辑语义判断。美国范围证据必须匹配实际原文并核对其位置，总部背景片段不能充当标的所在地；不以有限美国城市名单作为硬门槛。这些检查不能代替完整地理语义核查。

4. 脚本执行来源限额、栏目软目标和排除规则。新日报先核对 editor 的 market_scope；明确海外、不明或缺失美国范围的条目不进入写稿池。标题或主题片段出现海外地域时，须有美国主资产／市场的连续原文证据，海外投资方收购美国资产仍可保留。全国住宅／Sunbelt／BTR／CRE／机构资本目标为 5／4／3／5／3，重要性优先，同档稿件动态参考栏目已选数与目标之比、尚未覆盖的具体资产、原始研究及规则分。同一出版集团通常最多 3 条；必需研究源的系统性重大原始研究最多额外 1 条，并记录原因。同次 FOMC 决策另作保守事件防重：需要可读官方会议日期锚、主标题为政策决定、日期证据和可核对的利率结果；明确区间冲突或日期有歧义时不猜测合并。代表实际入选后才标记事件已覆盖。不同统计期、地区及有独立新增数据的研究不因提及 Fed 被合并。
5. 新日报从编辑已通过的材料里冻结最多 26 条写稿池，前 20 条为主选，其余为候补。先用一次有界批量写稿；程序保留好卡，优先以同栏目、同资产候补替换失败卡，补足原主选数后即可封版。重要性 4／5 的主选仍须保留。原栏目有稿时不得因写作故障清空该栏。来源及资产计数按实际刊出集合重算。

同一模型以显式 `low` 生成中文卡片及中英文速读摘要。日报直接提供标题和前 1,800 字符冻结正文，模型仅返回标题、摘要、影响和速读，引用不参与生成；脚本从窗口绑定可读原文节选用于英文卡片展示。数字按实际提供的窗口校验，百分比另核对原文同值百分比单位。该检查仍不能验证全部主体、统计期、方向或因果。周／月报继续按原段提供正文及 1～3 连续段的 evidence_id 选项，由程序截取实际 evidence_quote。短句也保留为分析材料，多句选项不省略中间内容。冻结、缓存和公开结构继续保存实际引文。日报标记 writing_policy 为 daily-pool-v1；旧刊按原契约读取。中文摘要 `text` 按规范化后的全部非空白 Unicode 字符计数，目标约 200、硬上限 250，其中英文字母、数字和标点均计入；对应英文 `text_en` 合计最多 150 个空白分隔词。逐句双语共用 `item_ids`，数字均核对同一原文；英文拒绝缺失或含中文。周月报主线同时生成 `title`／`title_en`，不增加翻译调用。
6. 脚本核对 ID、逐字证据、数字、标签及摘要长度，确定性修正中文排版。英文日期月份全称和日期语境中的常用缩写可转换为中文数字月份，仅限“数字＋月”的日期位置，支持月份所有格、with／by／before／after／ahead of、明确的月份事件短语及 commit on 月份语境，排除后接大写专有名词的机构名，不把机构／人名或周期词转换成无依据数值；原文未直接列出的差额、基点及增长率仍拒绝。CRE 子类优先使用逐稿受控资产标签，兼容旧稿标题识别；酒店拆除后拟建住宅等项目按拟建用途分类。日报先按最终刊出集合复验双语速读，只保留引用全部已刊的完整中英文句对；无合格句对时记录 summary_status=unavailable 并在两种语言显示缺失提示，正文可以封版。选稿另记录 `selection_target=20`、实际选出数和缺口；`content_target` 仍指写稿计划，不改变不足额封版门槛。页面分别展示选稿与写稿计数，并显示正文／时效覆盖缺口。候选逐条记录出版、编辑排除、范围未验证、来源限额及写稿暂缓等去向。通过后写期刊文件，最后写 `latest.json`。生成失败保留上一期。

数字保持原值或精确单位换算，不接受四舍五入，即使带“约”；数值失败反馈指出字段及可用原值。数字依据在最终中文排版格式上校验，数值区间中的连字符与正文双连字符不作为负号；独立负数仍需原文支持。保存的卡片、摘要和主线在恢复时重新检查，只复用合格部分；无效部分进入原有额度约束的局部修复，不因文件齐全而重复失败。

生成端先独立校验完整 metadata；全部摘要句与主线内容合格、唯一问题为摘要长度时，保留中英文共同的最长连续完整句前缀后全量重验。坏卡不会迫使模型重写已合格或可安全裁剪的 metadata。首句超过中文 250 字符或英文 150 词仍失败，不截句、跳句或删稿。裁剪会减少速读主题，原新闻卡片保留；原长度、保留句数和最终长度记录在内部诊断，并随合格 metadata 恢复。已刊契约保持严格，不在检查归档时自动裁剪。新刊以 `editorial_schema: 2` 标记双语及脚本归栏契约；旧归档保留原契约与栏目。英文界面按语言选择摘要／主线，旧档缺少英文时显示英文缺失提示，不回退中文。

请求使用 JSON object 模式，并检查完整响应。每阶段 3 次物理请求内允许最多两次内容纠错，与网络重试共用次数及时间账本。编号及去重关系明确时，选稿只纠正非法条目的四维语义字段与地域证据，保留原 keep／importance／capital_focus／reason／duplicate_of，合并后复验全局去重图；结构或引用关系有歧义时才完整纠正。写稿按稳定 ID 分别保存合格卡片及摘要／主线。编号归属明确时，只修失败或缺失卡片；卡片全部合格而摘要失败时，只修摘要／主线。坏卡与无法确定性处理的 metadata 同时有错时合并修复，保留已通过卡片，最终完整重验。未知／重复编号仍拒绝该回答，不接收截断 JSON。日报在请求结束或交付预留点，可按明确门槛封版：刊出不少于原主选 80%、缺口不超过 3 条、重要稿和已有栏目均保留。暂缓的原主选及替补关系保存在本期 writing_plan，输入原文留在本期快照，不自动移入次日。周／月报仍要求全部入选稿通过。只有日期而无时刻的报告记录 day 精度，网页展示日期；不能拿服务器本地时区猜具体发布时间。

正常流程为 2 次模型调用；瞬时网络错误可能增加重试，精确请求缓存命中会减少调用。网络重试和契约纠正共用每阶段最多 3 次请求的上限，不再整轮重跑流水线；写稿失败不会再次调用已完成的选稿。同版两阶段共用 11 分钟模型耗时预算，网络请求、退避和未完成请求的预留时间跨运行累计；活动请求也受剩余预算约束。各刊可读目标前给发布预留 3 分钟；迟到恢复继续受原次数和时间上限限制。单请求总上限 240 秒、首个网络响应字节等待 150 秒，收到数据后按 90 秒无数据判定断流；默认退避 15／45 秒。永久路由错误立即失败。这些措施只恢复已经启动的任务，不能保证平台按时启动。

逐次请求在 `state/llm-diagnostics/` 保存阶段、尝试、请求散列、本地及上游标识、完成原因、耗时和已收到的 usage；未收到 usage 记为 null。失败回答有大小上限，诊断统一脱敏，不写入 Git。Actions 在任务成功或失败后均尝试上传诊断，原料失败 artifact 继续保留。数字校验不是完整事实核查，也不能验证因果判断。

## 阶段与交付

每期由 kind、period_key、cutoff_upper、revision 标识。常规重试冻结原料与实际证据，复用通过校验的决策、卡片和摘要；分阶段附件提供换 runner 恢复，Actions cache 仅作加速。额度账本缺失时，仍可恢复已验证缓存或现成候选，禁止猜测剩余额度并继续调用。

生成先产出 ready 候选，发布器独立合并当前远端状态、提交白名单文件并确认推送；随后核验生产首页、latest、归档和日期索引，收据单独保存。来源覆盖、内容通过和交付状态分别记录。已有归档而派生文件缺失时只恢复交付，不重新生成。

恢复合并与公开输入快照会去除完全相同的来源观测，保留不同检查时间、成功／失败和覆盖区间，防止重复恢复使文件倍增。完整冻结附件保持不变；发布前检查白名单文件，超过 GitHub 普通文件 100 MiB 限制时明确失败并保留候选，不继续提交或推送。

阶段、固定版本恢复及只读截止检查命令见 [恢复说明](docs/RECOVERY.md)。外部观察调度与通知由独立配置控制。

## 研究来源及可追溯性

共配置 77 个采集入口，其中 46 个为研究类入口。HAR、Zillow Research、Realtor.com Research 和 NAR Research 是必需监测源。完整机构清单、入口形式与访问限制见 [研究覆盖说明](docs/source-coverage.md)。

“已配置”不代表实时抓取已通过。403、仅预览、目录截断、正文不足及日期缺失分别记录，不绕过登录或付费限制，也不为机构凑稿。页面显示研究检查状态；缺少必需来源或历史覆盖证据时标记为 `degraded`。合法的 complete／degraded 同期归档都可复用，来源缺口不触发自动重建；补齐新材料使用显式新修订。

INVH、AMH 的 SEC 入口保留既有 ID 与水位，并以公司官方 IR RSS 为补充；RSS 的相对正文链接按实际入口解析，保留原始公告标题和发布时间。这两个来源使用 Node 内置 HTTPS，列表、补文及待处理候选沿用同一来源配置，不新增依赖。SEC 联系请求头只发送到 SEC 域名。关键 BTR 来源失败、近期正文不可读或日期全部缺失，会进入栏目覆盖诊断并标记 `degraded`，不能把空栏解释为没有重要消息。

页面“来源与行业覆盖”显示各资产本期及近 5 个工作日已记录的入选数量，包括自存储、老年住房、生命科学和跨资产；未分类稿另列。滚动统计按真实工作日日期检查，缺刊明确提示，入选为零也不代表市场无消息。内部诊断同时记录各栏候选、达到质量门槛及入选数量；比例是同档选稿的软约束，不为填齐 sector 降低证据或质量标准。

`state/collection-checkpoint.json` 保存各源水位与待处理原始材料；逐条 acquisition_window 记录可追溯的采集区间，首次发现的超期材料记为 null。模型失败后可续跑，成功发布后只消费冻结版本实际处理的材料指纹，pending 保留截稿后材料和冻结后新增／变更的材料；忽略 Git 的 collection-cache.json 另保留最近原始池，恢复推送失败或模型失败的任务。`state/snapshots/` 保存采集原料，包括待核实的补采旧稿，不局限于入选稿；`state/inputs/` 保存实际模型候选、初始去重状态、出版排除原因和覆盖信息。周月报使用这些采集快照，旧日报的入选条目只作为补充。没有原始快照的日期不能声称已完整覆盖。补文后 `insufficient_evidence` 形成正文缺口；无效日期／更新日期待核实另列时效未验证，明确超期或超过截稿点不算正文故障。列表正常不能抵消正文缺口。覆盖区间还需有效来源状态和日期跨度证据，不把一次当前抓取自动当成整周历史。

## 本地运行

需要 Node.js 22 或更新版本；PDF 提取使用 Poppler 的 `pdftotext`。当前项目不需要 npm 运行依赖。复制 `.env.example` 为 `.env`，填写已有兼容路由的密钥、完整 Chat Completions URL 和模型名。该路由必须支持 `reasoning_effort`、`max_completion_tokens`、流式响应及完成原因；先运行小额探针验证，不能假定中转会透传参数。

```bash
npm test
node --env-file=.env scripts/probe-model.mjs
node scripts/validate-sources.mjs --research-only --enrich --output .tmp/source-check/report.json
npm run build
npm run build:weekly
npm run build:monthly
```

生产构建受日历约束。手动强制重建仅限工作日：`FORCE_RUN=1 npm run build`。三类构建均可设置 `LLM_SKIP=1`，但必须同时设置隔离的 `NEWS_DATA_DIR` 和 `NEWS_STATE_DIR`，防止覆盖正式数据。历史 `PUBLISH_NOW` 和回放也强制要求隔离。

```bash
NEWS_DATA_DIR=.tmp/replay/data NEWS_STATE_DIR=.tmp/replay/state \
REPLAY_SNAPSHOT=state/inputs/daily-2026-10-28.json \
PUBLISH_NOW=2026-10-28T01:00:00Z node --env-file=.env scripts/build.mjs

npm run evaluate -- --output .tmp/ab/report.json

# cases.json: [{"kind":"daily","now":"2026-10-22T01:00:00Z"}]
node --env-file=.env scripts/evaluate-models.mjs --snapshot .tmp/source-check/report-snapshot.json \
  --cases .tmp/ab/cases.json --output .tmp/ab/models
npm run preview
```

模型对照脚本固定同一输入，比较编辑 medium／low，写稿均为 low；最多 4 个明确历史案例，所有输出与状态隔离。来源或解析规则变化时，本地验收使用新的状态目录；CI 按来源配置与解析模块散列隔离缓存。

回放读取固定输入，不请求来源；要完全离线再加 `LLM_SKIP=1`。回放可在周末执行验证，生产任务仍不运行。历史构建不写项目首页。评估脚本使用旧稿固定评分，只比较确定性选稿，不能估计漏报召回率、摘要质量或 token 节省比例。

本地预览地址为 `http://localhost:8080`。9 号 r1 数据已先行恢复并通过线上核验；两轮独立复审结论及引文匹配限制见 [9 号恢复验收](docs/validation/2026-11-09-daily-recovery-and-budget-fix.md)。上线配置和检查点缓存见 [部署说明](docs/DEPLOY.md)；摘要与周／月恢复发布的验证及限制见 [发布验收](docs/validation/2026-11-02-periodicals-release.md)，早间调度和模型对照的历史证据见 [早间时间验收](docs/validation/2026-10-28-morning-deadline.md) 和 [模型／选稿对照](docs/validation/2026-10-28-reliability.md)。

## 代码入口

- `scripts/lib/sources.mjs`：采集、目录发现、正文与 PDF。
- `source-http.mjs`：指定来源使用的原生 HTTPS、重定向及条件请求响应。
- `calendar.mjs`：北京时间守卫、各刊可读目标、美东周／月自然周期及覆盖缺口。
- `news-core.mjs`：解析、规则评分和确定性去重。
- `editorial.mjs`：候选预算、编辑契约、来源限额和证据校验。
- `editor-evidence.mjs`：新日报的冻结原文编号、事件／地域角色约束及绑定验收。
- `llm-client.mjs`：参数、超时、重试、完整响应与缓存。
- `model-references.mjs`：模型批内短编号与内部稳定 ID 的映射。
- `event-groups.mjs`：有明确官方日期与政策结果证据的 FOMC 主事件分组。
- `editorial-coverage.mjs`：栏目来源缺口、逐资产统计及 5 个工作日的历史缺刊诊断。
- `pipeline.mjs`：日报、周报和月报的阶段协调。
- `issue-contract.mjs`／`issue-store.mjs`：期刊契约、冻结阶段、规则散列与额度账本。
- `artifact-recovery.mjs`／`restore-issue.mjs`：可信阶段附件恢复。
- `publication.mjs`／`publish.mjs`：候选发布及远端冲突处理；`delivery.mjs`／`check-publication.mjs`：线上核验和只读截止观察。
- `config/sources.json`：采集入口和出版集团；`config/tags.json`：标签词表。
- `public/`：无框架前端；`api/`：Vercel 定时触发守卫。

旧 `adaptive-window.mjs`、`digest-core.mjs`、`themes.mjs` 及其测试保留作旧行为比较，不在新版生产生成链中。旧 `WRITER_MODE`／`LEGACY_PICKER` 配置不再切换生成路径。
